# Points & Recognition

A [Chickadee Bandit](https://chickadeebandit.com/app-library/points-recognition) app.

Award points to members for participation, attendance, and volunteering. Live leaderboard with per-period resets — a social currency system for org engagement.

## Features

- Points for participation, attendance, and volunteering.
- Live leaderboard.
- Per-period resets.

## Install

In your hub, go to **Apps → Install from URL** and paste:

```
https://github.com/firebirdsystems/chickadeebandit-points-recognition/releases/latest/download/bundle.json
```
